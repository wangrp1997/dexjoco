# DexContactRAM V2 方法论（历史版本）

> 当前唯一权威规范为 `METHODOLOGY.md`。本文件保留 V2 演进、失败实验和接口历史，不再单独定义创新主线或验收标准。

## Continuous Visuotactile State Tracking and Mode-Gated Compliant Control for Bimanual Dexterous Insertion

最后更新：2026-08-22

## 1. V2 定位

DexContactRAM V2 面向固定 CAD 装配几何下的双臂灵巧手插孔任务。π0.5 继续负责目标理解、双手抓取、搬运、孔口附近粗对准以及失败后的重抓；独立小脑负责持续视觉—触觉状态跟踪、接触模式判断和毫米级柔顺插入。

V2 不再把“检索成功轨迹并通过 SQP 变形”作为主算法，也不在第一阶段实现完整粒子 POMDP。核心闭环收敛为：

```text
π0.5 粗操作
→ 持续视觉跟踪工件与孔
→ 触觉/腕力判断接触和滑移
→ 四状态模式机
→ 模式条件柔顺控制
→ 安全检查与高频重规划
→ 插入完成或交还 π0.5 重抓
```

V1 的检索、信念空间 SQP 和配对 rollout 模块保留为实验对照和局部工具，但不再代表 V2 的完整主线。

## 2. 问题本质与设计原则

该任务的主要困难不是生成一条几何上通向孔底的轨迹，而是执行过程中同时存在：

- π0.5 粗对准误差；
- 左右手抓持姿态差异；
- 工件和托盘在手内微滑；
- 视觉遮挡和传感延迟；
- 孔口碰撞、单边接触、双边卡紧和正常插入等模式切换；
- 双手高刚度形成闭链内力。

因此 V2 遵循五条原则。

1. **视觉持续工作**：视觉不是只在首帧提供初始化，而是在整个精密阶段持续跟踪。
2. **触觉负责接触修正**：触觉和腕力主要用于判断接触、滑移、卡紧和插入阻力，不单独承担全局位姿恢复。
3. **先模式判断，后连续控制**：不同接触模式使用不同控制律，避免用一个局部线性模型跨越所有模式。
4. **环境接触用于机械对准**：允许柔顺接触消除剩余误差，而不是要求视觉状态先达到理想零误差。
5. **复杂度逐级增加**：只有简单闭环无法达到验收门槛时，才增加主动探测、多假设信念或技能检索。

## 3. π0.5 与小脑的职责边界

### 3.1 π0.5 大脑

π0.5 负责：

- 理解任务和选择目标工件、目标孔；
- 完成双手抓取、抬升和搬运；
- 将工件移动到孔口附近；
- 保证工件与孔进入 V2 小脑的接管区域；
- 在 handoff 中提供当前任务意图定义的名义接近轴；该轴属于上游动作语义，不是物体真值；
- 可选地在 handoff 中提供短时双腕 action/twist chunk，表达接近路径和双手协同意图；
- 接收小脑的重抓、换姿态或退出请求；
- 处理掉落、严重遮挡、抓持失效和不可恢复卡紧。

V2 不修改、不微调 π0.5，也不在 π0.5 动作上叠加高频残差。

短时 action chunk 属于控制权交接消息，而不是小脑对仍在运行的 π0.5 动作叠加残差。handoff 后 π0.5 暂停执行，小脑根据真实传感对该意图进行重定时、限幅、双手约束释放、安全停止和必要的局部修正。

### 3.2 V2 小脑

小脑负责：

- 估计工件—孔相对状态；
- 跟踪双侧抓持稳定性；
- 判断当前接触模式；
- 生成双腕和手指的短时柔顺命令；
- 限制接触力、腕力、滑移和动作幅度；
- 在每个控制周期重新估计并更新控制；
- 判断何时完成、暂停、退出或交还 π0.5。

## 4. 在线可用观测

V2 在线只能读取真实机器人可获得的观测：


\[
y_t=
\left(
I_t^{base},I_t^{wristR},I_t^{wristL},
q_t,\dot q_t,
f_t^{tipR},f_t^{tipL},
w_t^R,w_t^L,
u_{t-1}
\right).
\]

其中包括：

- 外部/ego 相机图像；
- 左右腕部相机图像；
- 双腕 TCP 位姿和手指编码器；
- 左右指尖接触力或触觉代理；
- 左右腕部六维力/力矩；
- 历史执行命令。

MuJoCo 工件位姿、托盘位姿、真实接触点和真实接触力只能用于离线训练标签和控制器外部评测。它们禁止参与 handoff 选择、在线状态初始化、模式切换、控制参数选择、规划、动作生成和安全门控；测试 episode 也禁止使用真值做在线校准。

## 5. 持续视觉—触觉状态

### 5.1 控制状态

圆柱工件的主要控制状态仍采用五维装配状态：

\[
s_t=
\left[
e_{x,t},e_{y,t},
\theta_{x,t},\theta_{y,t},
d_t
\right].
\]

其中：

- \(e_x,e_y\)：工件入孔端相对孔轴的横向偏差；
- \(\theta_x,\theta_y\)：工件轴相对孔轴的倾斜；
- \(d\)：插入深度，孔口上方为负，进入孔内后增加。

附加状态包括：

\[
g_t=
\left[
q_t^R,q_t^L,
\rho_t^R,\rho_t^L,
c_t^R,c_t^L
\right],
\]

其中 \(\rho^R,\rho^L\) 表示左右抓持稳定分数，\(c^R,c^L\) 表示左右触觉接触分布或低维接触特征。

### 5.2 坐标约定

控制命令定义在 Franka TCP/attachment-site 坐标系，手—物附着定义在 Allegro palm body 坐标系。所有几何传播必须显式应用固定安装变换：

\[
{}^WT_{palm}
=
{}^WT_{tcp}{}^{tcp}T_{palm}.
\]

工件几何使用真正进入孔内的碰撞几何端点，不能使用抓持端或可视化 site。当前 round-8mm 工件的入孔端在工件 body 中为：

\[
p_{insert}^{P}=[0,0,0.0135]\ \mathrm m.
\]

### 5.3 持续视觉估计

视觉估计器在每个控制周期输出：

\[
(\hat s_t^v,\Sigma_t^v,r_t^v),
\]

其中 \(r_t^v\in[0,1]\) 是视觉可靠度。视觉模块应使用连续帧而不是固定首帧 embedding，并显式利用：

- 工件和孔的 CAD/几何模板；
- 前一帧姿态作为跟踪先验；
- 外部相机的全局视角；
- 双腕相机的局部近距离视角；
- 相机遮挡、出视野和关键点一致性检查。

视觉网络不直接回归绝对五维状态，也不把全局或 pooled embedding 交给另一个黑盒状态回归器。固定 CAD 已知时，视觉模块必须先输出保留像素空间结构的几何观测，再由确定性几何求解器恢复装配 primitive。

冻结约束：单目图像中的工件端点与孔口中心像素重合不能替代三维横向对准。两者深度不同时存在透视视差，安全纠偏必须使用 CAD 尺度、轮廓、已标定相机、可部署深度证据或接触证据恢复度量关系。纯单目图像误差加在线像素雅可比已被 held-out 仿真反例否定，禁止作为 ALIGN 主控制律。

空间观测分为：

- 工件实例掩码；
- 孔座实例掩码；
- 工件入孔端中心和轴线上至少两个点；
- 工件可见轮廓切线、端面椭圆或矩形端面角点；
- 孔口中心、孔口轮廓采样点和孔轴点；
- 孔座/托盘上至少四个非共线 CAD 基准点，用于确定孔座完整姿态；
- 每个观测的热图、可见概率和像素协方差。

MuJoCo 对象真值只在离线回放中生成二维热图、CAD 对应、实例轮廓、可见性和相机监督。部署时网络只能读取 RGB；教师三维点、分割和深度不得进入推理进程。

#### 5.3.1 孔座 CAD 姿态

设孔座 CAD 基准点为 \(P_i^S\)，图像观测为 \(u_i^c\)，相机投影为 \(\pi_c\)。孔座姿态通过带鲁棒核的多视角重投影优化求解：

\[
\hat T_{WS}
=
\arg\min_{T_{WS}}
\sum_{c\in\mathcal C_t}
\sum_i
w_{i,c}
\rho\!\left(
\left\|
\pi_c(T_{WS}P_i^S)-u_i^c
\right\|_{\Sigma_{i,c}^{-1}}^2
\right)
+\lambda_{sil}E_{sil}(T_{WS}).
\]

初始化使用 `solvePnPRansac`；随后最小化关键点重投影误差和 CAD 轮廓到预测轮廓的距离。参与集合 \(\mathcal C_t\) 由在线可靠度门控决定，不能默认三相机等权。

孔口中心和孔轴由 CAD 固定变换得到：

\[
p_h^W=\hat T_{WS}p_h^S,
\qquad
a_h^W=\hat R_{WS}a_h^S.
\]

#### 5.3.2 工件对称几何

圆柱工件绕自身轴的旋转对插入无意义，不估计不可观测的 roll。工件视觉状态为入孔端 \(p_p^W\)、单位轴 \(a_p^W\) 和已知 CAD 半径/长度。其解通过端点、轴线、端面和轮廓共同约束：

\[
(\hat p_p^W,\hat a_p^W)
=
\arg\min_{p,a,\|a\|=1}
E_{tip}+\lambda_aE_{axis}+\lambda_cE_{contour}+\lambda_tE_{temporal}.
\]

矩形工件可使用端面角点和侧面 CAD 点直接执行 PnP。对圆柱工件，姿态空间按绕轴旋转等价类处理，禁止为了凑完整 SE(3) 而回归不可观测角度。

#### 5.3.3 五维状态的确定性计算

几何求解得到工件与孔 primitive 后，五维控制状态由几何关系直接计算，不再学习回归：

\[
e^W=(I-a_h^Wa_h^{W\top})(p_p^W-p_h^W),
\]

\[
d=-a_h^{W\top}(p_p^W-p_h^W),
\]

\[
\omega=\log\!\left(R_h^{W\top}R_p^W\right),
\qquad
s=[e_x^H,e_y^H,\omega_x^H,\omega_y^H,d].
\]

其中 \(H\) 是由孔座 CAD 姿态确定的孔坐标系。圆柱工件的 \(R_p^W\) 只要求其第三轴等于 \(a_p^W\)；绕第三轴分量不进入五维状态。

#### 5.3.4 在线可靠度与失败处理

可靠度必须来自可部署观测证据，并显式区分：

- `in_frame`：投影位置是否位于图像范围内；
- `visible`：该位置附近是否存在对应工件或孔座实例像素；
- 热图峰值与空间熵；
- 轴两点间距与 CAD 投影尺度是否一致；
- 多相机三角化残差；
- 连续帧重投影残差。

不能使用教师三维误差、MuJoCo 分割或真值可见性作为在线可靠度。腕相机关键点出画或被手遮挡时，融合器应降低该视角权重，由外部相机和时间先验维持跟踪，而不是强行输出高置信姿态。当前数据进一步表明三相机不能等权融合：外部相机作为主估计视角，腕相机只有在关键点可见概率、热图集中度、实例分割支持和跨视角重投影残差同时通过门控时，才作为局部增益观测。

若有效 CAD 对应少于 PnP/对称几何求解所需数量、重投影残差超限或 Hessian 条件数过差，视觉模块必须返回低可靠度并停止输出新的绝对状态。允许使用上一帧和本体做短时传播，但不得退化为 learned feature→state 回归或静默使用教师真值。

### 5.4 本体传播

视觉帧之间使用双腕运动传播状态：

\[
\hat s_{t|t-1}
=
f_{kin}
(\hat s_{t-1},\Delta T_t^R,\Delta T_t^L).
\]

本体传播只在短时间内保持连续性，不将“手掌运动等于物体运动”视为永久成立。检测到抓持滑移或视觉重新出现时必须修正。

### 5.5 触觉与腕力修正

触觉和腕力不直接回归绝对装配姿态，而用于生成事件：

```text
free_contact
rim_contact
bilateral_contact
insert_contact
jammed
right_slip
left_slip
grasp_failure
```

事件由力幅值、力方向、接触数量、左右差分、历史变化率和视觉状态共同判断。触觉事件用于：

- 限制视觉不确定方向；
- 判断孔口接触侧；
- 判断是否允许继续下探；
- 触发降低刚度、退回或交还 π0.5；
- 增大滑移方向的状态不确定性。

### 5.6 简化融合

V2 第一阶段采用可靠度加权融合：

\[
\hat s_t
=
K_t\hat s_t^v
{}+(I-K_t)\hat s_{t|t-1},
\]

其中 \(K_t\) 根据视觉协方差、遮挡分数和触觉事件调节。接触发生后不盲目相信视觉单帧跳变；视觉长期失效时不允许无限本体积分，而应暂停、退回或交还 π0.5。

如果该简化融合无法达到验收门槛，再升级为模式条件 EKF、因子图或粒子信念，但这不是第一阶段前置条件。

## 6. 四状态柔顺控制器

V2 使用一个可解释的有限状态机：

```text
ALIGN
→ GUARDED_DESCENT
→ CONTACT_CORRECTION
→ INSERT
```

任意状态均可进入：

```text
RETREAT / REGRASP_REQUEST / SUCCESS
```

### 6.1 ALIGN：视觉对准

进入条件：

- π0.5 已完成稳定双侧抓持；
- 工件位于孔口附近但尚未形成明显孔壁接触；
- 视觉可靠度满足最低要求。

控制目标：

\[
e_x,e_y\rightarrow0,
\qquad
\theta_x,\theta_y\rightarrow0,
\]

同时保持插入深度基本不变。该阶段使用视觉伺服和低速双腕协调，不允许提前快速下压。

退出条件：

- 横向与倾斜进入预对准漏斗；
- 或发生孔口接触，切换到 CONTACT_CORRECTION；
- 或视觉失效、抓持失效，进入 RETREAT。

### 6.2 GUARDED_DESCENT：受保护下探

进入条件：预对准误差满足宽松阈值。

名义接近轴必须来自 π0.5 handoff 的显式动作意图，或来自通过可靠度门控的度量视觉。禁止从任意短动作历史盲猜带符号孔轴；held-out 回放已出现历史方向与实际插入方向相反的反例。

自然 handoff 普查进一步表明，仅保留一根固定接近轴会丢失成功轨迹中的时变平移、旋转和双手协调：固定轴 guarded descent 仅 `2/9`，使用记录 action chunk 作为 π0.5 意图代理时为 `8/9`。因此第一版 handoff 接口必须允许短时双腕意图，而不能只传一个目标孔轴。

沿孔轴方向以低速下探：

\[
v_z=v_{guard},
\qquad
|v_{guard}|\leq v_{safe}.
\]

横向和旋转方向采用低刚度，轴向使用力阈值停止。若检测到孔口接触，不继续强制下压，而切换到 CONTACT_CORRECTION。

### 6.3 CONTACT_CORRECTION：接触修正

该状态利用孔口接触进行机械对准。

原则是：

- 接触法向方向柔顺或退让；
- 接触切向方向允许小幅搜索；
- 双手不同时保持全方向高刚度；
- 根据左右抓持稳定性选择主手和柔顺手；
- 发现双边卡紧时先退回，不继续增加轴向力。

控制律可写为：

\[
u_t
=
u_{visual}
{}+u_{contact}
{}+u_{damping},
\]

其中 \(u_{visual}\) 修正可见误差，\(u_{contact}\) 根据接触侧生成切向修正，\(u_{damping}\) 抑制振荡和腕力增长。

若接触修正后满足进入条件，则切换到 INSERT；若力持续增加、深度不增加或双侧腕力方向显示卡紧，则进入 RETREAT。

### 6.4 INSERT：柔顺插入

进入条件：

- 横向误差和倾斜位于插入漏斗内；
- 当前接触不是卡紧；
- 双侧抓持仍稳定；
- 轴向力低于安全阈值。

控制采用轴向推进、横向柔顺和旋转柔顺：

\[
v_z>0,
\qquad
K_{xy}<K_z,
\qquad
K_{\theta}<K_z.
\]

插入过程中持续检查：

- 深度是否单调增加；
- 轴向力是否异常增长；
- 横向力是否持续偏置；
- 左右手是否发生滑移；
- 视觉与本体状态是否长期不一致。

达到目标深度并满足孔底接触条件时进入 SUCCESS。

### 6.5 RETREAT 与 REGRASP_REQUEST

以下情况立即停止继续插入：

- 力/力矩超过硬安全阈值；
- 深度连续多个周期不增加且轴向力增加；
- 双边卡紧；
- 一侧抓持进入 gross-slip；
- 视觉长期失效且状态不确定性超过阈值；
- 控制器连续修正仍无法进入插入漏斗。

可恢复时退回到孔口上方并重新 ALIGN；不可恢复时向 π0.5 输出结构化请求：

```text
regrasp_peg
regrasp_tray
move_to_visible_pose
increase_coarse_clearance
abort_task
```

## 7. 双手协调与约束释放

V2 不要求两只手在所有方向同时高刚度。根据抓持稳定性和接触模式选择：

- 工件手主导、托盘手柔顺；
- 托盘手保持孔位置、工件手柔顺；
- 一侧位置控制、一侧力/阻抗控制；
- 暂时降低某侧横向或旋转刚度；
- 发现过约束时先释放刚度再继续修正。

刚度选择必须满足：

\[
K_t^R,K_t^L\in\mathcal K_{safe},
\]

并限制单周期变化，防止控制器在模式切换时产生冲击。

第一阶段不主动设计大幅手内滑移；微滑被视为需要估计和限制的扰动。只有在简单柔顺控制无法达到目标后，才将受控滑移正式加入动作空间。

## 8. 局部优化和检索的降级角色

### 8.1 SQP

SQP 只允许在以下条件下使用：

- 当前接触模式稳定；
- 视觉/融合状态达到部署精度；
- 局部动力学矩阵条件数可接受；
- 动作—腕力响应已经辨识；
- 求解器输出逐约束 violation，而不是只依赖状态码。

SQP 的作用是优化一个短时模式内动作，不负责跨模式恢复，也不负责从错误抓持中强行生成插入轨迹。

### 8.2 检索

V2 第一阶段可以不启用轨迹检索。后续若引入检索，检索对象应是：

- 状态机参数；
- 主手/柔顺手选择；
- 各模式速度、力阈值和刚度；
- 接触修正方向；
- 技能适用域和失败模式。

检索结果是控制先验，不是必须回放或变形的完整轨迹。

## 9. 离线训练与数据

### 9.1 视觉监督

MuJoCo 真值用于生成：

- 工件入孔端和孔轴标签；
- 五维装配状态标签；
- 遮挡和视野有效性标签；
- 多相机一致性标签；
- 手内滑移标签。

数据划分必须按 episode 隔离，训练、校准、验证和测试不能共享同一 episode 的相邻帧。

### 9.2 接触事件监督

接触标签包括：

- free；
- rim contact；
- bilateral contact；
- normal insertion；
- jammed；
- right/left micro-slip；
- grasp failure；
- bottom contact。

在线模型只能读取真实传感通道，教师接触真值只用于离线监督和评测。

### 9.3 控制参数标定

成功数据用于初始化速度、力阈值和刚度范围，但经验包络不能直接等同于物理可行性。所有安全阈值必须同时通过：

- 成功数据统计；
- 失败数据压力测试；
- MuJoCo 扰动实验；
- 硬件量程和控制频率检查。

## 10. 分阶段验收

V2 采用严格门控，上一阶段未通过时不得增加更复杂模块。

### P0：坐标和几何链

- TCP 到 palm 固定变换正确；
- 工件入孔端和孔坐标正确；
- 非线性几何传播和数值雅可比一致；
- 单元测试全部通过。

### P1：回放视觉估计

在 held-out episode 连续视频上评估视觉状态：

- 横向 P90 不超过 1.2 mm；
- 倾斜 P90 不超过 0.03 rad；
- 深度 P90 不超过 3 mm；
- 遮挡时可靠度下降必须可校准；
- 禁止读取教师几何特征。

### P2：无 Oracle 视觉—触觉闭环

控制器从 handoff 到插入完成只能读取第 4 节定义的真实可部署传感通道。MuJoCo 真值由独立 evaluator 记录，不能返回控制进程。

- 连续插入成功至少 8/10；
- 不只验证首步，必须连续执行到成功或明确退出；
- 无硬安全阈值超限；
- 所有失败必须能区分估计失败、控制失败、抓持失败和视觉失效。

若 P2 低于 8/10，停止增加检索、POMDP 和复杂优化，先修视觉与四状态控制器。

### P3：随机化与未见抓持

增加：

- 未见工件抓持姿态；
- 未见托盘抓持姿态；
- 摩擦、质量和接触刚度扰动；
- 相机位姿、照明和纹理扰动；
- 不同 π0.5 粗对准结果。

通过后再考虑检索、主动探测、粒子信念或受控滑移。

## 11. 失败归因要求

任何汇总成功率必须同时报告：

- `success`：连续插入完成；
- `safe_retreat`：安全退出但未完成；
- `controller_failure`：控制逻辑未找到恢复动作；
- `estimation_failure`：状态误差或可靠度判断失败；
- `grasp_failure`：π0.5 handoff 后抓持不可用；
- `solver_failure`：数值求解失败但物理约束可能可行；
- `safety_violation`：执行超出硬安全阈值。

不能把 `safe_retreat` 统计为成功，也不能把 solver 状态码直接等同于物理不可行。

## 12. V2 创新点

V2 的创新不再表述为“用 SQP 变形检索轨迹”，而是：

1. π0.5 与独立精密小脑之间的明确控制权交接；
2. 持续多视角视觉与双侧触觉/腕力的接触阶段融合；
3. 面向双侧抓持闭链的模式门控柔顺控制和约束释放；
4. 从粗对准到插入完成的可解释四状态连续闭环；
5. 严格区分插入成功、安全退出、估计失败和数值求解失败。

当 V2 基础闭环达到稳定成功率后，检索可以进一步学习不同抓持和接触条件下的控制参数与技能适用域，但它不是基础控制器成立的前提。

## 13. 方法边界

V2 当前不声称：

- 解决任意未知物体和未知孔型；
- 在无视觉、无触觉或严重遮挡下持续完成插入；
- 对所有抓持姿态都能恢复；
- 在任意接触模式下保证全局最优；
- 使用当前仿真回滚雅可比直接部署真实机器人；
- 通过高拒绝率证明控制器安全有效。

V2 的目标是先在固定装配几何和真实可用传感通道下证明：持续视觉—触觉跟踪与模式条件柔顺控制能够从 π0.5 的粗对准结果稳定完成连续插入。

## 14. 当前实现状态

V2 已开始独立落代码：

- `v2_boundary.py`：递归拒绝 teacher、oracle、privileged geometry 和物体真值字段进入 V2；
- `v2_contact.py`：只使用指尖力、双腕力和视觉估计生成抓持稳定、孔口接触、卡紧、滑移和孔底事件；
- `v2_control.py`：实现 ALIGN、GUARDED_DESCENT、CONTACT_CORRECTION、INSERT，以及 RETREAT、REGRASP_REQUEST 和 SUCCESS；
- `v2_cerebellum.py`：将真实传感器观测、视觉估计、接触事件和双腕 44D 动作生成串成统一入口；
- `intent_chunk_execution.py`：冻结 π0.5 显式 handoff 返回的真实双腕 action chunk，并使用腕力进行重定时、单步限幅和硬力退让；策略未提供 `handoff` 时不允许用教师或仿真真值替代触发。

当前尚未实现通过 P1 的持续视觉估计器和无 Oracle 连续仿真 runner，因此现阶段只证明接口隔离、状态转换、柔顺动作方向和安全退出逻辑通过单元测试，不代表已达到 P1/P2 成功率门槛。

持续视觉第一版已完成三路视频 10 Hz 对齐缓存和 CLIP pooled embedding 基线。全量 82 个 episode 的孔口局部窗口结果仍为厘米级误差，未通过任何部署门，因此该语义 embedding 被明确拒绝接入控制器。实际腕部画面包含清晰工件轮廓和孔口边缘，下一版应保留空间特征，采用 CAD 关键点/轮廓热图与多视角几何，而不是继续调节 pooled CLIP 回归。

2026-08-22 已完成空间视觉监督链路与 RGB 空间基线第一版：

- `spatial_visual_supervision.py`：实现 MuJoCo 相机模型投影、工件/孔座实例语义掩码、四关键点、遮挡可见性和高斯热图工具；
- `build_spatial_visual_supervision.py`：从记录初始状态准确回放 episode，生成三相机二维关键点、深度、相机内外参和 4 倍下采样语义掩码 sidecar；
- sidecar 明确标记 `teacher_only=true`、`allowed_online_inputs=false`，不改变 V2 传感防火墙；
- 构建过程中发现原始 LeRobot 视频为 `640×640`，教师 MuJoCo 分割渲染为 `320×240`；已显式缩放相机内参和二维关键点，并在教师渲染坐标中计算可见性，禁止混用两个像素坐标系；
- episode 1、frame 248 的原始视频叠加验证通过：缩放后四关键点准确落在原始 RGB 的工件和孔座上；
- 新增空间视觉单元测试，覆盖 MuJoCo `-z` 相机投影约定、实例类别隔离、可见性、掩码下采样和热图生成。

全量监督与 RGB 基线结果：

- 82 条 episode、6401 个 10 Hz 帧，split 为 train 5502、validation 440、test 459；
- `spatial_visual_learning.py` 与 `train_spatial_visual_model.py` 实现共享三相机轻量编码器、工件/孔座分割、四关键点高斯空间交叉熵和可见性分类；推理只读取 RGB 和相机编号；
- 冻结 epoch 6 后，test 工件/孔座分割 IoU 为 `0.631 / 0.841`，可见性准确率 `0.841`、Brier `0.0819`；
- test 外部相机四关键点 P90 为 `4.46 / 5.01 / 2.40 / 2.32` 个 160×160 输出像素，对应原始图约 `17.8 / 20.0 / 9.6 / 9.3 px`；
- 左腕相机 test P90 仍为 `30.2 / 21.4 / 22.2 / 38.4` 输出像素；右腕孔口在 4 条 test episode 中没有可见监督样本；
- 全视角总体 test P90 为 `16.61` 输出像素，明显由腕相机长尾主导，因此 `approved_for_multiview_fusion=false`，尚未通过 P1。

当前下一步不是等权三角化，也不是把教师投影接入控制。应先实现 RGB 推理可靠度和视角门控，以外部相机为主估计；同时针对腕相机采用可见 ROI、相机专用头或更强局部特征，只有腕部 held-out 长尾明显下降后才允许参与几何融合。之后再评测多视角重投影误差和五维装配状态 P1 门控。

随后完成的 ego-only 五维可观测性诊断进一步修正了路线：

- `ego_visual_state_estimation.py` 从冻结 ego RGB 模型提取 38D 空间特征，包括四关键点、热图集中度、可见概率、实例支持、轮廓矩和相对图像几何；
- 6401 帧 ego 特征缓存完全由 RGB 推理生成，不读取教师几何；
- 仅用 ego 空间特征的线性五维回归在 local test 上为横向 P90 `21.1 mm`、倾斜 P90 `0.208 rad`、深度 P90 `30.6 mm`，失败；
- 教师二维关键点＋轮廓矩的 ExtraTrees 诊断上界仍为横向 P90 `14.1 mm`、倾斜 P90 `0.237 rad`、深度 P90 `40.3 mm`，说明问题不只是网络二维误差或 ridge 容量；
- 加入可部署的 46D 本体和 44D 历史动作后，三帧 ExtraTrees 在冻结 local test 数值误差改善到 `4.36 mm / 0.137 rad / 18.8 mm`，但 validation 为 `6.21 mm / 0.160 rad / 35.5 mm`；
- 更关键的是横向修正方向在 validation/test 的同半平面正确率仅 `72.9% / 56.6%`，45 度内正确率仅 `45.8% / 32.1%`，不满足安全视觉伺服要求；
- 因此 `approved_for_p1=false` 且 `approved_for_visual_coarse_alignment=false`。不能因为 test 数值误差偶然通过宽松阈值，就忽略 validation 失败和动作方向错误。

方法论据此停止“从单个 ego 视角的学习特征直接回归绝对五维状态”支线。下一版粗对准应直接闭环最小化可观测图像误差，并通过安全小扰动在线辨识动作—像素雅可比；深度主要由低速 guarded descent 和接触事件确定。外部相机继续提供主图像误差，腕相机仅在可靠度门控通过时补充局部观测。只有图像误差闭环能够稳定给出正确修正方向后，才重新讨论几何五维融合。

随后完成的 held-out 图像雅可比实验进一步否定了上述“直接最小化单目图像误差”假设。episode 17 的四维投影雅可比仅秩 `3/4`；episode 23 虽然二维像素误差下降，但外部三维横向误差从 `3.5067 mm` 恶化到 `3.9136 mm`。因此纯单目图像误差闭环正式停止，详细记录见 `EXPERIMENT_LOG_V2.md`。ALIGN 只能使用带度量深度约束的 CAD/轮廓几何，或降级为视觉限定搜索范围后的 guarded descent＋接触局部搜索，不能再把像素重合当作物理对准。

首个无 Oracle 接触控制原型进一步显示：双手动态运动分配在一个困难 held-out 状态中由失败变为成功，并在另一状态中将峰值腕力残差从约 `0.816 N` 降至 `0.467 N`；但所有有效 rollout 均未触发接触微探测。因此当前只允许声称“闭链约束释放有初步正信号”，不能声称接触响应搜索已经成立。下一门控必须使用可重复 rim-contact 初态直接比较固定分配与动态分配。

自然 handoff 普查随后取代了人工 rim-contact 计划。固定轴下探为 `2/9`，记录的时变双腕 action chunk 代理达到 `8/9`；自然失败主要来自丢失上游运动意图后的姿态漂移，而不是已观察到的稳定卡边。V2 主线据此冻结为“π0.5 短时双腕意图＋独立小脑传感安全执行”。当前 `8/9` 不能算 P2，因为意图来自同 episode 记录且成功由外部 evaluator 终止。

在线评测现已支持真实 OpenPI chunk 的显式控制权交接：仅当策略响应包含 `handoff=true` 时冻结该 chunk，随后停止 π0.5 重规划，由独立执行器根据腕力重定时、限制单步增量并在硬力时退让。另有 `online_pi05_chunk` 冻结评测模式，教师只确定自然 handoff 实验初态，初态后的意图来自真实 π0.5 在线推理而非记录后续动作。前者检验完整交接接口，后者快速检验真实 chunk 可用性；后者不等价于自动 handoff。当前本轮无在线策略服务，因此只有接口与单元验证，不是 P2 实验结果。

随后已完成 9 个自然 held-out handoff 的真实在线 chunk 验证，结果为 `8/9`，与记录动作代理一致。该结果支持“保留 π0.5 时变双腕意图”是自然插入阶段的必要接口，而非示范回放偶然性。唯一失败 episode 17 在 100 个控制周期内仍未完成受限 chunk，且倾斜误差增大；后续应归因执行 horizon、动作限幅与局部估计，而不是重新引入固定轴或人工卡边搜索。由于 handoff 初态和成功终止仍由外部实验系统提供，该结果尚不等于 P2 通过。
